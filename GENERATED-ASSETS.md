# Red Velvet generated visual assets

This package includes four original, AI-generated, non-explicit editorial images used by the Red Velvet Live Club visual theme:

- `client/public/assets/red-velvet-hero-luxe.jpg` — homepage hero
- `client/public/assets/red-velvet-room-after-dark.jpg` — After Dark room/stage
- `client/public/assets/red-velvet-garden-ritual.jpg` — nature/luxury lounge
- `client/public/assets/rubina-editorial.jpg` — Rubina companion panel

The production WebDev project references CDN-hosted copies so its checkpoint remains lightweight. This ZIP variant references the bundled local files for portable development.
